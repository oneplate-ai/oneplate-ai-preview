Today AI Bite

October 26, 2026

This issue looks at changes in an API for structured decisions, security technology for sensitive data, and the way development teams can turn collaboration notifications into code work.
Announced capabilities and availability can differ from real accounts and workflows, so we also note what to verify before adoption.

1. OpenAI’s Decisions API is now generally available. OpenAI release notes

On October 22, OpenAI announced that the Decisions API using GPT-6 Luna is generally available. The developer API is designed to present a model with multiple questions or choices and return structured results that can support decision workflows.
OpenAI’s release notes say one request can contain up to 400 questions, accept images and structured JSON inputs, and cache shared input across requests to reduce cost.

This may be useful for applications that classify surveys, compare candidates, or review documents in a consistent format. A model’s selection is not automatically a correct answer or an approval, so teams still need thresholds, human review, and error-handling rules.

  • Who should care: API teams that need structured comparisons or decisions across many inputs.
  • Availability: OpenAI marked the feature generally available on October 22, 2026. Check account access and pricing again immediately before publication.
  • Why it matters: It expands an API from returning generated text toward representing repeated decision processes as structured data.
  • What to watch: Do not replace final human decisions with automated output; test input quality, bias, and error cases separately.

2. Cohere started a public beta for confidential computing in Model Vault. Cohere announcement

On October 22, Cohere announced a public beta for confidential computing in Model Vault. Confidential computing aims to protect data not only while it is stored or transmitted, but also while a model is processing it, using hardware-based isolation.
Cohere says prompts, documents, and responses can travel through an encrypted request path, while customers can use remote attestation to verify an environment based on NVIDIA H100 GPUs and Microsoft Azure.

Organizations handling financial records, clinical data, legal documents, or source code may consider this approach when plain-text processing on external infrastructure is difficult to accept. Confidential computing does not automatically solve application vulnerabilities, prompt injection, data governance, or regional retention requirements.

  • Who should care: Security and engineering teams evaluating managed AI services for sensitive enterprise data.
  • Availability: Cohere said the NVIDIA H100-based public beta began on October 22, 2026. Verify regions, contracts, and technical conditions in the live account and documentation.
  • Why it matters: It offers a way to verify the processing environment technically, rather than relying only on a provider contract.
  • What to watch: Evaluate attestation policy, remaining metadata, availability, region, regulatory requirements, and application security separately.

3. GitHub’s Microsoft Teams app can turn notifications into coding work. GitHub changelog

On October 23, GitHub announced that its Microsoft Teams app now connects GitHub Copilot coding capabilities to notifications. After receiving an issue or pull-request notification in a team conversation, a user can call `@GitHub` to investigate, fix, test, and create a pull request using the surrounding context, according to GitHub.
The workflow is designed to turn a notification into a starting point for work without leaving the conversation.

The resulting changes still need the team’s review, tests, and merge process. GitHub says existing GitHub notifications users should update to the integrated app, while the legacy app is scheduled to retire on November 16, 2026, so administrators should check connected repositories and permissions.

  • Who should care: Teams that receive repository notifications in Microsoft Teams and handle development work there.
  • Availability: GitHub published the feature in its October 23, 2026 changelog and directed existing app users to update.
  • Why it matters: It connects notifications, conversation, and code changes into one response path.
  • What to watch: Limit repository permissions, review responsibility, test scope, and cost according to team policy.

The short version.

These announcements show AI expanding beyond answer generation into decision APIs, protected data infrastructure, and development collaboration flows.
Before adopting any of them, check who reviews the result and how far the organization can control data, permissions, and costs.
