오늘 AI 한입

2026년 9월 14일

이번 호는 AI가 소프트웨어를 시험하고, 새로운 방식으로 이야기를 보여 주며, 코드 리뷰를 더 깊게 돕는 세 장면을 살펴봅니다.
AI가 결과를 내는 속도만큼 그 결과를 확인할 수 있는 증거와 사람의 판단도 중요합니다.

1. OpenAI가 소프트웨어를 시험하고 결과를 보여 주는 사례를 소개했습니다. OpenAI 공식 발표

OpenAI는 9월 11일, Cognition의 Devin이 GPT-6 Astra를 사용해 자신이 만든 소프트웨어를 테스트하고 작동 결과를 보여 주는 사례를 소개했습니다.
Devin은 자율적으로 소프트웨어 작업을 수행하는 도구이며, 이번 사례에서는 아이폰 게임을 시뮬레이터에서 실행한 녹화와 통과한 검사·아직 확인하지 못한 영역을 담은 보고서를 함께 돌려줍니다.

이 방식은 AI가 코드를 만들었다는 말에서 멈추지 않고 실제 실행 증거를 함께 제시하려는 시도입니다.
다만 사례와 성능 설명은 OpenAI와 Cognition의 발표이므로, 개발팀은 녹화와 보고서의 범위가 충분한지 직접 확인해야 합니다.

  • 누구에게 해당하나: AI 코딩 도구를 사용하거나 소프트웨어 테스트를 자동화하려는 개발팀입니다.
  • 현재 상태: Cognition의 적용 사례로 소개됐으며, 일반 개발자가 같은 기능을 동일한 조건으로 이용할 수 있다는 뜻은 아닙니다.
  • 왜 중요한가: 자동화된 코드 작업에서도 결과를 재현하고 확인할 수 있는 자료가 필요하기 때문입니다.
  • 주의할 점: 녹화와 보고서는 테스트의 일부만 보여 줄 수 있으며, 사람이 테스트 범위와 위험을 최종 검토해야 합니다.

2. Google이 Gemini와 함께 만든 XR 이야기 프로젝트를 공개했습니다. Google 공식 발표

Google은 9월 11일, 제83회 베니스 국제영화제에서 공개되는 세 가지 확장현실(XR) 프로젝트를 소개했습니다.
XR은 현실 공간에 디지털 화면이나 상호작용을 겹쳐 보여 주는 기술을 뜻하며, 이번 프로젝트에는 Gemini 대화형 AI와 Vertex AI가 활용됐습니다.

예를 들어 ‘NEVATARS’는 Gemini 기반 대화와 상호작용을 넣은 혼합현실 애니메이션이고, ‘Galápagos: The Last Eden’은 디지털 찰스 다윈과 대화하는 자연 탐험 경험으로 소개됐습니다.
Google은 기술을 앞세우기보다 사람의 창의성을 중심에 둔 이야기 경험을 만들려는 방향을 보여 줬습니다.

  • 누구에게 해당하나: 영상·게임·전시 등 새로운 이야기 형식을 실험하는 창작자와 관람객입니다.
  • 현재 상태: 9월 11일 발표된 영화제 공개 프로젝트이며, 이용 가능 범위와 체험 방법은 프로젝트별로 다를 수 있습니다.
  • 왜 중요한가: AI가 글이나 그림을 만드는 데서 나아가 관객과 상호작용하는 이야기의 일부가 될 수 있음을 보여 주기 때문입니다.
  • 주의할 점: 프로젝트 소개와 기술적 효과는 Google의 설명이며, 실제 체험 품질은 기기와 현장 조건에 따라 달라질 수 있습니다.

3. GitHub Copilot 코드 리뷰가 더 많은 도구로 코드를 확인하도록 개선됐습니다. GitHub 공식 변경 안내

GitHub는 9월 11일, Copilot 코드 리뷰가 셸 도구를 사용해 빌드와 테스트를 실행하고, Lite 검토에서는 여러 에이전트가 각자의 관점에서 결과를 만드는 개선을 발표했습니다.
코드 리뷰는 코드를 합치기 전에 다른 사람이 변경 내용을 살펴보는 절차이며, 셸 도구는 명령어를 실행해 코드를 확인하는 기능입니다.

GitHub는 이 변경을 통해 Copilot이 코드를 더 넓게 검증하고 중요도가 높은 문제를 더 잘 찾도록 했다고 설명했습니다.
다만 수치와 효과는 GitHub의 실험 결과이므로, 각 팀은 자신의 언어·빌드·테스트 환경에서 결과를 따로 확인해야 합니다.

  • 누구에게 해당하나: 풀 리퀘스트 검토를 자동화하려는 개발팀과 플랫폼팀입니다.
  • 현재 상태: GitHub Copilot 코드 리뷰의 업데이트로 제공되며, 실제 적용 범위는 사용 중인 제품과 요금제 조건을 확인해야 합니다.
  • 왜 중요한가: AI가 파일만 읽는 데서 그치지 않고 실제 검사 명령을 실행해 검토 근거를 넓히려는 방향이기 때문입니다.
  • 주의할 점: 자동 리뷰는 사람의 승인이나 보안 검토를 대신하지 않으며, 실행된 검사와 빠진 범위를 함께 확인해야 합니다.

오늘의 한 줄 정리.

AI를 업무와 창작에 넣을수록 결과 자체보다 어떻게 확인했는지 보여 주는 구조가 중요해지고 있습니다.
