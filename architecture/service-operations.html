개인 서비스 운영 허브 구조

자동 운영 상태와 GUI 기반 계획·아이디어 기록을 분리하고, 한 화면에서 결합합니다.

VPS · GITHUB · NOTION
사용자 입력계획 데이터VPS 자동 수집외부 서비스

1. 기록과 수정

Notion에서는 서비스별 아이디어와 작업을 카드·보드·타임라인으로 편집합니다. Notion 접근이 막힌 사내망에서는 Hermes CLI에 자연어로 입력하면 VPS가 Notion API에 기록합니다.

2. 자동 운영 상태

VPS 수집기는 서비스 프로세스, 컨테이너, 공개 URL, GitHub CI·커밋을 읽기 전용으로 확인합니다. 운영 화면에는 필요한 결과만 전달합니다.

3. 한 화면의 판단

운영 허브는 “서비스가 정상인가”와 “다음에 무엇을 할 것인가”를 함께 보여줍니다. 초기에는 Grafana·별도 DB·유료 모니터링 없이 구성합니다.

제안 구조도 · 실제 배포 전에는 Notion 데이터베이스 설계, 접근 경로, 상태 수집 범위를 확정합니다.
